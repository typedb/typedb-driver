=== FileCompression

`class`

*Package*: `TypeDB.Driver.Api`



The compression of a database export data file. Zstd compression uses level 3, the zstd default, and includes a content checksum. Imports detect compressed data files automatically.

 
  database.ExportToFile("schema.tql", "data.typedb", FileCompression.Zstd);
