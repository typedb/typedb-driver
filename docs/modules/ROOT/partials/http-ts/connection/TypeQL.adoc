=== TypeQL

`class`

A piece of TypeQL query text that can only come from code: the literal parts of a ``typeql`` template, labels checked by ``TypeQL.label()``, variables checked by ``TypeQL.variable()``, integer literals checked by ``TypeQL.integer()``, and other fragments built the same way. Values are never part of it: they are passed to the query as given rows.

A ``TypeQL`` fragment can be passed to ``query``, ``oneShotQuery`` and ``analyze`` in place of a query string.

==== method ``integer``

[source,typescript]
----
integer(value: number): TypeQL
----

Makes an integer literal fragment, for the clauses that only take a literal, not a given parameter: ``limit`` and ``offset``. Throws a ``TypeError`` if ``value`` isn't a safe integer.

==== method ``label``

[source,typescript]
----

Makes a fragment from a type label (``person``), a scoped role label (``friendship:friend``), or the name of a function, struct or struct field. Throws a ``TypeError`` if ``name`` isn't a valid TypeQL identifier, or is a reserved keyword.
