=== FileCompression

`class`

*Package*: `typedb.api.database.file_compression`

This class is used to specify the compression of a database export data file. Imports detect compressed data files automatically.

[caption=""]
.Examples
[source,python]
----
database.export_to_file("schema.typeql", "data.typedb", FileCompression.ZSTD)
----
